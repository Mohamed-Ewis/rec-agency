# رك إيجنسي — نظرة عامة على المشروع

رك إيجنسي مكتب تشغيل داخلي لفريق **توظيف تقني** صغير وخبير. المنتج ليس نسخة من لينكدإن، وليس نظام تتبع مرشحين معقّدًا. نحن نبيع الوصول إلى الأشخاص المناسبين، لا كومة من السير الذاتية.

هذا المستودع هو **المرحلة الأولى**: واجهة Nuxt 3 ببيانات تجريبية واقعية. لا يوجد Laravel ولا قاعدة بيانات ولا سحب آلي من لينكدإن.

## ماذا يفعل النظام

المكتب ذو اتجاهين، أقرب لمنتج مسؤول توظيف منه لكومة سير:

1. **إيجاد أشخاص للعملاء** — ابحث في مجمع المواهب مقابل موجز حي، ثم أضفهم إلى مسار العميل.
2. **إرسال الوظائف لطالبي العمل** — طابق تفويضًا مفتوحًا مع شخص، أرسل ملاحظة تجريبية بالبريد أو لينكدإن، وتابع الرد.
3. **تحصيل الأتعاب** — التعيين يُنشئ فاتورة العميل، نافذة الضمان، وحصة مسؤول التوظيف.

التطبيق يحوّل هذه الحلقة إلى لوحة واحدة مضغوطة:

| القسم | الغرض |
|---|---|
| لوحة التحكم | قرارات الأسبوع: الوظائف المفتوحة، المقابلات، العروض، الوظائف المُرسلة، الأتعاب المعلّقة |
| الوظائف | التفويضات: الموجز، المالك، المسار، المواهب المقترحة، إنشاء / إيقاف / إغلاق |
| المرشحون | من نمثّلهم، وظائف مرتّبة، إرسال موجز |
| العملاء | الشركات، جهات الاتصال، الأتعاب، التعيينات |
| البحث | بحث بأسلوب Recruiter مقابل وظيفة عميل |
| إرسال الوظائف | طابور التواصل: صياغة، إرسال (تجريبي)، رد / رفض |
| العمولات | التعيينات، الفواتير، الضمان، حصة المسؤول |
| المسار | من «مصدر» إلى «عُيّن» — التعيين يرفع الفاتورة |
| المقابلات | القادمة والسابقة مع الملاحظات |
| النشاطات | خط زمني موحّد للبريد ولينكدإن والمكالمات والملاحظات |
| المهام | عمل بتاريخ استحقاق — الإرسال ينشئ متابعة |
| التقارير | التعيينات، التحويل، الحمل، عمولة المسؤول |
| المستخدمون | الأدوار وتفعيل الحساب (المدير) |
| الإعدادات | إعدادات مساحة العمل |

## التقنيات

- Nuxt 3 و Vue 3 Composition API و TypeScript
- Pinia لحالة المكتب
- Tailwind CSS
- مستودعات تجريبية في `data/` — تُستبدل لاحقًا بواجهات Laravel

## التشغيل محليًا

```bash
npm install
npm run dev
```

أو `yarn install` ثم `yarn dev`. افتح العنوان الذي يظهر في الطرفية (غالبًا `http://localhost:3000/` أو `http://localhost:3001/`).

## تسجيل الدخول

المصادقة تجريبية. **الدور ليس سوى مجموعة صلاحيات باسم**. الشاشات والأزرار تفحص `can(المورد، الإجراء)`.

| الاسم | الدور | البريد | كلمة المرور |
|---|---|---|---|
| مايا تشن | مدير | maya@rec-agency.agency | Maya-Admin-26 |
| جيمس أوكونكو | مسؤول توظيف | james@rec-agency.agency | James-Desk-26 |
| إلينا فارغا | مسؤول توظيف | elena@rec-agency.agency | Elena-Desk-26 |
| بريا شاه | مدير تسليم | priya@rec-agency.agency | Priya-Lead-26 |
| توم هيل | مشاهد | tom@rec-agency.agency | Tom-View-26 |

المدير يستطيع تغيير دور مستخدم آخر وتفعيل الحساب أو تعطيله. لا يمكن إنزال آخر مدير نشط أو تعطيله.

## الصلاحيات (الحالية)

| | مدير | مدير تسليم | مسؤول توظيف | مشاهد |
|---|---|---|---|---|
| الوظائف / المرشحون / العملاء / المسار | كامل | عرض وتعديل | إنشاء وتعديل | عرض |
| البحث / إرسال الوظائف | كامل | عرض وتعديل | إنشاء وتعديل | عرض |
| العمولات | كامل | عرض وتحصيل | عرض | عرض |
| التقارير | نعم | نعم | عرض | لا |
| المستخدمون | نعم | لا | لا | لا |
| كتابة الإعدادات | نعم | لا | لا | لا |

## مراحل التسليم

1. **الآن** — الواجهة + بيانات ثابتة + حراسة المسارات والإجراءات
2. **بعدها** — واجهة Laravel، مصادقة حقيقية، حفظ الوظائف والمرشحين والمسار
3. **ثم** — رفع السيرة، توصيات الذكاء الاصطناعي، البريد والتقويم
4. **لاحقًا** — تكاملات لينكدإن/Recruiter ولوحات التوظيف المعتمدة فقط. لا نبني السحب الآلي كأساس.
