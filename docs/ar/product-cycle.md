## ارتباط السجلات

```mermaid
flowchart LR
  العميل --> الوظائف
  الوظائف --> البحث
  البحث --> إرسالالوظيفة
  إرسالالوظيفة --> الفرز
  الفرز --> الإرسالللعميل
  الإرسالللعميل --> المقابلات
  المقابلات --> العرض
  العرض --> التعيين
  التعيين --> العمولة
  العمولة --> الفاتورة
```

العلاقة بين المرشح والوظيفة **متعددة إلى متعددة**. الشخص قد يكون حيًا على موجزين؛ والموجز قد يحمل مسارًا كاملًا.

## شكل السجلات

**الوظيفة** — العنوان، العميل، الوصف، إلزامي / مرغوب، المستوى، الراتب، الموقع، نمط العمل، الأولوية، الحالة، المالك، التواريخ.

**المرشح** — الهوية، التواصل، لينكدإن، ملخص السيرة، المهارات، الخبرة، توقع الراتب، التوفر، المصدر، المالك، الوسوم، الملاحظات.

**العميل** — الشركة، جهات الاتصال، القطاع، الموقع، الأتعاب / الاتفاق، الوظائف، الملاحظات، النشاط.

**النشاط** — بريد، لينكدإن، مكالمة، ملاحظة، مقابلة، مهمة، تغيير حالة.

**الفرصة** — وظيفة أُرسلت لطالب عمل: القناة، الموضوع، النص، أُرسل / رد / رفض.

**التعيين المالي** — تعيين: الراتب، نسبة أتعاب العميل، المبلغ، حصة المسؤول (40%)، الفاتورة، تواريخ الضمان.

## طبقة الذكاء الاصطناعي (النية)

درجات المطابقة التجريبية موجودة اليوم على صفوف المسار. لاحقًا يمكن أن تأخذ الواجهة نفسها خرج النموذج الحقيقي:

- تحليل وصف الوظيفة والسيرة
- درجة المطابقة، المهارات المتوافقة، الناقصة، والشرح
- أسئلة فرز، مسودة تواصل، ملخصات
- اقتراح الخطوة التالية

خرج الذكاء الاصطناعي يبقى **توصية**، وليس قرار تعيين تلقائي.

## المصادقة والأدوار

الوصول **صلاحية أولًا**. الدور حزمة باسم (`jobs:create`، `users:edit`، …). حراسة المسارات والأزرار تستدعي `can(المورد، الإجراء)`.

- **مدير** — كل شيء، بما فيه المستخدمون وكتابة الإعدادات وتحصيل الأتعاب
- **مسؤول توظيف** — البحث، إرسال الوظائف، تشغيل المسار؛ عرض العمولات
- **مدير تسليم** — رؤية الفريق والتقارير وتحديد الفواتير كمدفوعة
- **مشاهد** — قراءة المكتب والتعيينات؛ بلا تقارير وبلا كتابة
