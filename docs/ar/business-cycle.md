## الحلقة

```mermaid
flowchart LR
  A[اكتساب العميل] --> B[تأهيل الاحتياج]
  B --> C[استلام الوظيفة]
  C --> D[البحث]
  D --> E[تأهيل المرشح]
  E --> F[التواصل]
  F --> G[الفرز]
  G --> H[القائمة القصيرة]
  H --> I[الإرسال للعميل]
  I --> J[المقابلة]
  J --> K[العرض]
  K --> L[التعيين]
  L --> M[الضمان]
  M --> N[الفاتورة]
  N --> O[العلاقة]
  O --> A
```

| الخطوة | ماذا يحدث |
|---|---|
| 1. اكتساب العميل | إيجاد الشركة وبناء العلاقة |
| 2. تأهيل العميل | الشركة، الدور، الراتب، الاستعجال، شروط الأتعاب |
| 3. استلام الوظيفة | تحويل الاحتياج إلى وظيفة: المهارات، المستوى، الموقع، الراتب، إلزامي / مرغوب |
| 4. البحث | لينكدإن Recruiter، الإحالات، اللوحات، قاعدة البيانات، المجتمعات |
| 5. تأهيل المرشح | السيرة / لينكدإن، الخبرة، التوفر، الراتب، الموقع، الدافع |
| 6. التواصل | رسالة شخصية ومتابعة منتظمة |
| 7. الفرز | مكالمة قصيرة وأسئلة أساسية |
| 8. القائمة القصيرة | أفضل الأشخاص مع سبب ودرجة |
| 9. الإرسال للعميل | إرسال القائمة القصيرة |
| 10. إدارة المقابلات | تنسيق الجولات وتسجيل الملاحظات |
| 11. العرض | متابعة العرض والتفاوض والتنسيق |
| 12. التعيين | Hired |
| 13. الضمان / البديل | متابعة فترة الضمان إن وُجدت في العقد |
| 14. الفاتورة والإيراد | الأتعاب، الفاتورة، الدفع، العمولة |
| 15. العلاقة | العودة إلى العميل والمرشح للفرصة التالية |

## مراحل المسار

**مصدر → تم التواصل → مهتم → فرز → مؤهّل → مُرسل → مقابلة → عرض → عُيّن**

حالات جانبية: **مرفوض**، **انسحب**، **معلّق**.

لوحة كانبان في `/pipeline` هي هذا المسار. سحب البطاقة يغيّر المرحلة تجريبيًا دون حفظ خلفي.

## قواعد التشغيل

- لا مرشح بلا مصدر وبيانات اتصال وحالة واضحة
- لا وظيفة بلا عميل ومتطلبات واضحة
- كل تواصل مهم يُسجَّل في خط النشاط
- المرشح يمكن أن يرتبط بأكثر من وظيفة
- الوظيفة يمكن أن تضم عدة مرشحين
- الذكاء الاصطناعي يوصي. القرار للبشر. لا نعيّن بناءً على الدرجة وحدها
- ترتيب البناء: يدوي / ثابت → واجهة برمجية → تكاملات → أتمتة

## مؤشرات المكتب

الوظائف المفتوحة، المرشحون النشطون، المقابلات، العروض، التعيينات، الوظائف المُرسلة لطالبي العمل، الردود المنتظرة، نافذة الضمان، الإيراد، الأتعاب المعلّقة.

لوحة التحكم تعرض الشريحة التشغيلية: ما هو مفتوح، ما هو متوقف، من لديه حمل زائد، أي وظائف أُرسلت، وأي فاتورة تجاوزت الاستحقاق.

البحث وإرسال الوظائف هما نصف المنتج الشبيه بـ Recruiter. المسار والعمولات هما نصف الإغلاق والتحصيل. التواصل في هذه المرحلة يُسجَّل فقط — لا يصل إلى صندوق بريد حقيقي ولا إلى لينكدإن.
