## Run / التشغيل

```bash
npm install
npm run dev
```

Then sign in at `/login`. Demo accounts are listed in the docs and on the login screen.

ثم سجّل الدخول من `/login`. حسابات التجربة مذكورة في التوثيق وفي شاشة الدخول.

Phase 1 is Nuxt 3 + mock data only. Laravel comes later.  
المرحلة الأولى واجهة Nuxt 3 وبيانات تجريبية فقط. Laravel لاحقًا.
